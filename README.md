# threejs-study

Three.js 学习记录项目，基于 Vite 搭建。

## 技术栈

- [Three.js](https://threejs.org/) `^0.185.1`
- [Vite](https://vitejs.dev/) `^8.2.0`

## 运行

```bash
npm install
npm run dev
```
